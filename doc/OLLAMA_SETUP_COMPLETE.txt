💻 PYTHON INTEGRATION

Example 1: Simple job categorization
```python
import requests

def analyze_job(description):
    url = "http://localhost:11434/api/generate"
    payload = {
        "model": "mistral",
        "prompt": f"Categorize this job (Backend/Frontend/DevOps/Data): {description}",
        "stream": False
    }
    response = requests.post(url, json=payload)
    return response.json()["response"]
```

Example 2: Full job analysis
```python
def full_analysis(job_data):
    url = "http://localhost:11434/api/generate"
    prompt = f"""
    Analyze this job and provide:
    1. Category
    2. Seniority level
    3. Key skills needed
    4. Estimated salary range

    Title: {job_data['title']}
    Description: {job_data['description']}
    """
    payload = {
        "model": "mistral",
        "prompt": prompt,
        "stream": False
    }
    response = requests.post(url, json=payload)
    return response.json()["response"]
```

🎯 USE CASE: JOB ANALYSIS PIPELINE

1. Scraper fetches job from Indeed/Dice → Store in MongoDB

2. Listener picks up job from Kafka

3. Ollama analyzes:
   - Extracts skills
   - Categorizes (Backend/Frontend/etc)
   - Scores quality
   - Estimates salary

4. Results stored back in MongoDB with AI enrichment

5. Grafana dashboards show:
   - Distribution of roles by category
   - Skills in demand
   - Salary trends
   - Job quality statistics
