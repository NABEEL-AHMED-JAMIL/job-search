CUSTOMIZATION:
===============

To change colors, edit the log_colors dictionary in any file:

Example (in listener file):
  log_colors={
      'DEBUG': 'cyan',          # Change to: black, red, green, yellow, blue, purple, cyan, white
      'INFO': 'white',          # Change to: any of the above
      'WARNING': 'yellow',      # Add backgrounds: 'red,bg_white'
      'ERROR': 'red',
      'CRITICAL': 'red,bg_white',
  }

Available colors:
  Basic: black, red, green, yellow, blue, purple, cyan, white
  Backgrounds: bg_black, bg_red, bg_green, bg_yellow, bg_blue, bg_purple, bg_cyan, bg_white
  Combined: 'color,bg_color' (e.g., 'red,bg_white')

TROUBLESHOOTING:
================

Problem: Colors not showing up
Solution:
  1. Verify terminal supports ANSI colors
  2. Check if colorlog is installed: pip list | grep colorlog
  3. Restart terminal/Python session

Problem: Text is still plain
Solution:
  1. Verify colorlog==6.8.0 is in requirements.txt
  2. Run: pip install colorlog==6.8.0
  3. Restart Python process

Problem: Colors look different than expected
Solution:
  1. Different terminals render colors differently
  2. Check terminal color theme settings
  3. This doesn't affect functionality
