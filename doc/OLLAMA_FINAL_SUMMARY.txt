                        QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════════

START OLLAMA (3 commands):

  # 1. Start the service
  docker-compose -f docker-compose.ollama.yml up -d

  # 2. Pull a model
  curl http://localhost:11434/api/pull -d '{"name":"mistral"}'

  # 3. Open the UI
  http://localhost:3001

═══════════════════════════════════════════════════════════════════════════════
                      FULL STACK COMMAND
═══════════════════════════════════════════════════════════════════════════════

Start Everything (MongoDB + Kafka + Monitoring + Ollama):

  docker-compose -f docker-compose.full.yml \
    -f docker-compose.monitoring.yml \
    -f docker-compose.ollama.yml up -d

Then run your listeners:

  python -m etl.main.run_all_listeners
