HOW IT WORKS:
=============

Message Received
    ↓
Process Message
    ↓
  Success?
    ↙    ↖
  YES    NO
   ↓      ↓
commit() (skip)
   ↓      ↓
ACKNOWLEDGED  NOT ACKNOWLEDGED
   ↓              ↓
Won't retry    Will retry

PROCESS FUNCTION PATTERN:
=========================

BEFORE (No return value):
  def process_test_message(message):
      logger.info(f"Processing: {message}")

AFTER (Returns True/False):
  def process_test_message(message):
      try:
          logger.info(f"Processing: {message}")
          # Do business logic
          return True  # Success - acknowledge
      except Exception as e:
          logger.error(f"Failed: {e}")
          return False  # Failure - retry

MATCHES YOUR SENDER SIDE:

Sender (Java):
  .addCallback(
      result → handleSendSuccess(),  ← Success
      ex → handleSendFailure()       ← Failure/Retry
  )

Receiver (Python):
  if success:
      consumer.commit()              ← Message acknowledged (success)
  else:
      (no commit)                    ← Message NOT acknowledged (retry)
